核心能力

不止于存储，
更懂提炼与追溯

从上传到发布，从待办到追溯，每一个环节都为团队协作而设计。

LLM 智能编译

上传原始会议记录后，自动调用 LLM 提取标题、摘要、决策、待办、参会人、标签等结构化信息。支持 4 种场景化 Prompt 模板，可自定义模板与模型。

DeepSeek 智谱 MiniMax Kimi 自定义模板

四级权限体系

超级管理员、公司管理员、普通用户、只读用户四级角色，结合 ABAC 属性鉴权引擎，实现精细化的公司级数据隔离与操作权限控制。

ABAC 多租户 4 级角色 4 级密级

待办追溯 ⭐

每个待办事项携带原文上下文片段与位置索引，可一键跳转到会议原文对应位置并高亮显示。支持多负责人、状态流转、多维分组。

核心亮点 原文定位 多负责人 状态机

时间轴浏览

纵向时间轴视图，支持年/月/日三档切换，右侧月度走势图一目了然。内置全文搜索与标签筛选，历史决策快速定位。

年/月/日视图 走势图 全文搜索

安全分享

阅后即焚、限时访问、密码保护三种安全模式，分享链接 UUID 不可猜测，访问日志完整记录，分享者可随时撤销。

阅后即焚 限时访问 密码保护 访问日志

可视化备份管理

类 Windows 任务计划的备份策略配置，支持每日/每周/每月自动备份，本地/远程/云存储多目标，一键恢复，无需懂 cron。

自动备份 多目标 一键恢复

Word 文档导出

已发布会议一键导出为 Word 文档，支持单会议、决策清单、待办清单三种场景。基于 python-docx 原生构造，跨平台稳定，中文文件名兼容 RFC 5987 标准，权限按角色精细控制。

单会议 决策清单 待办清单 中文文件名 权限控制

LLM 供应商管理

支持 DeepSeek、智谱、MiniMax、Kimi 四大预置供应商及自定义 OpenAI 兼容接口。每个公司独立配置，模型级启用/禁用，一键测试连接。

供应商管理 模型测试 公司隔离

音频转写 ⭐

上传会议录音，自动调用 ASR 网关转写为结构化文本（说话人 / 时间轴 / 段落），转写结果可手动编辑后直接进入 LLM 编译流。3 个预置 ASR 引擎（FunASR / SenseVoice / Qwen3-ASR），分片上传 5 路并发 + 3 次指数退避，4GB 大文件稳定传输。

自动转写 说话人分离 结构化段落 4GB 大文件 3 引擎可切换

版本历程

持续迭代 · 精益求精

从 v1.13.0 到 v1.21.x，每一次发布都离「好用的会议管理工具」更近一步。

v1.21.x

音频转写集成（ASR）+ 任务队列权限与分页

v1.21.0 五批推进音频转写（ASR）集成，新增「音频转会议」数据源：上传录音 → 调用 asr-platform 统一网关 → 转写为结构化文本（说话人/时间轴/段落）→ 复用 LLM 编译流。3 个预置 ASR 引擎（FunASR / SenseVoice / Qwen3-ASR），分片上传 5 路并发 + 3 次指数退避。后续 12 个小版本持续打磨体验：v1.21.5 任务控制 + 标签对齐、v1.21.7 队列筛选冗余 + queueStats 统计失真修复、v1.21.9 智能轮询增强（替代 SSE 因安全考虑回退）、v1.21.10 类型错位修复 + 详情抽屉关闭按钮 + 转写状态不更新等 4 个端到端 bug、v1.21.11 任务队列权限收紧 + 分页 + 上传人标签、v1.21.12 普通成员 ASR 配置读取权限修复。

v1.20.x

登录页 M↔O 视觉对仗 + 备份稳定性攻坚

登录页引入巨型渐变 M 水印 + 同心圆 O 光晕背景，产品宣发页同步风格；备份功能 500 错误修复（Pydantic schema 必填约束错配）+ share_access_logs 表过滤策略错配修复 + 5 阶段步骤级日志 + 错误透传机制；备份策略管理重构（物理删除 + iOS 风格启用/禁用开关 + 自定义时间选择器）；第 3 次上线前安全审查（2 Critical + 18 Warning 系统性修复，ECIES 登录私钥轮换 + git 历史清理）。

v1.19.0

异步恢复 + 选择性恢复

恢复流程改用线程异步执行，前端轮询任务进度，永不超时；支持按内容类型（会议/待办/LLM 配置/Prompt 模板/用户/分享/上传文件/原始文件）选择性恢复，8 种内容类型复选框；移除"恢复前快照"高失败率步骤，恢复耗时从 5-15 分钟缩短到 1-3 分钟。

v1.18.3

备份恢复多租户隔离

备份和恢复按 company_id 隔离，A 公司备份不会泄露 B/C 公司数据；pg_dump 全库导出改为按表 + company_id 过滤；TRUNCATE 改为 DELETE 减少锁阻塞；4 张关联表（meeting_participants / todo_assignees / llm_models / share_access_logs）通过父表子查询过滤。

v1.17.1

导出功能精简为仅 Word

取消 PDF 导出（weasyprint 跨平台依赖不稳定），仅保留 Word 导出；export_service 从 770 行精简到 380 行；移除 markdown / weasyprint 依赖，保留 python-docx；中文文件名兼容 RFC 5987 标准（filename* UTF-8 编码）。

v1.17.0

Word 文档导出落地（PRD F25）

已发布会议一键导出 Word 文档，支持单会议 / 决策清单 / 待办清单三种场景；python-docx 原生构造（弃用 pandoc 方案）；数据源从 meeting.summary 改为编译产物（title/topic/attendees/summary/decisions/todos）；权限按角色精细控制（超管/公司管理员/上传者）。

v1.16.45

组件抽离 + 包结构治理

CompileDialog / ParticipantsDialog 组件抽离；数据库迁移动态反射；AwareDateTime 统一序列化；移除 sys.path.insert 副作用。

v1.16.43 - v1.16.44

安全加固与上线前审查

CORS 白名单收敛、JWT 密钥强制校验、登录失败持久化、slowapi 限流、ABAC fallback 改为 deny、破坏性迁移剥离运行时。修复 LLM 连通性测试阻塞主线程问题。

v1.16.32 - v1.16.36

整体化时区治理

统一 AwareDateTime 类型、AES-GCM 加密存储、ECIES 端到端加密登录。修复待办日期循环减 1 天、双冒号 bug、会议时间 +8h 错位等时区问题。

v1.16.8 - v1.16.39

多负责人与会议编辑重构

待办多负责人支持、MeetingEditorDialog 组件抽离、会议记录操作列编辑语义修正、待办卡片链接视觉强化、分享管理显示创建者姓名。

v1.13.0

MVP 发布

LLM 模型测试入口、密码强度校验与生成器、用户管理可用性修复、公司卡片计数。完成上传、编译、时间轴、待办追溯、分享、备份等核心功能。
